# OCLAST Dashboard

The OCLAST Dashboard is an efficient, full-stack application built to run state-of-the-art deep learning models for automated cell segmentation, circularity analysis, and spatial morphology mapping on _in vitro_, TRAP-stained osteoclasts.

## Tech Stack
* **Frontend:** React + Vite + Tailwind CSS
* **Backend:** FastAPI + Python
* **Inference Engine:** ONNXRuntime
* **Data Processing:** OpenCV & Scikit-image

## Features
* **Bento UI:** A gorgeous, glassmorphic floating dashboard layout for viewing high-resolution images.
* **Instant Inference:** Upload any `.jpg` or `.tif` biological image to instantly segment cells across the entire FOV.
* **Interactive Mask Editing & Eraser:** Click directly on segmentation masks to delete false positives, or trace missed osteoclasts using the freehand drawing tool with live morphometrics.
* **Consecutive Tile Naming:** Automatic `<image>_tile_<index>` labeling for intuitive spatial tracking.
* **Binary Ground Truth Mask Export:** Single-click approval workflow exporting full-resolution binary `.tif` masks (`_mask.tif`) and pairing source images for model retraining.
* **Deep Supervision Heatmaps:** Toggle between raw segmentation boundaries and confidence/saliency heatmaps generated by the ONNX models.
* **Extraction Library:** View tabular statistics for every cell (Area, Circularity) and export directly to CSV.

## Getting Started Locally

### Backend Setup
1. Create a Python virtual environment:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the FastAPI server (Port 8000):
   ```bash
   uvicorn api:app --host 0.0.0.0 --port 8000
   ```

### Frontend Setup
1. Open a new terminal and navigate to the frontend directory:
   ```bash
   cd frontend
   npm install
   ```
2. Start the Vite dev server (Port 5173):
   ```bash
   npm run dev
   ```

Visit `http://localhost:5173` to view the dashboard!

### Downloadabe file
Go to the lastest release on this Github repo and download the large .exe file. Opening this should allow the entire dashboard to run locally on your pc!
